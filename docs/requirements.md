# 要件定義書

## ペルソナ
RUNTEQで学習中でチーム開発意欲がある人。

## 事例
意欲はあるものの、どこで募集すればいいのか分からない。

現状は個別に誘っている。募集要項のようなものを示した上で募りたい。

## ユースケース表

| 区分 | ID | ユースケース | 概要 |
|---|---|---|---|
| MVP | UC-1 | SNS共有 | SNSで募集を見て、アプリを開く |
| MVP | UC-2 | 募集一覧の閲覧 | 募集内容を読んで、詳細を開く |
| MVP | UC-3 | 会員登録・ログイン | メールアドレスとパスワードで登録・ログインする |
| MVP | UC-4 | 申し込む | 応募完了 |
| MVP | UC-5 | 募集フォームに記入 | 募集要項を書く |
| MVP | UC-6 | 通知（メール） | 承認された、または応募が来たら通知が届く |

## ユーザーストーリー
- 手軽に募集内容を確認したい。なぜなら、チーム開発に興味あるから。
- 募集内容を見て応募したい。なぜなら、学習状況が揃っていて有意義なチーム開発を行えそうだから。
- 募集者・応募者間で連絡を取りたい。
- 募集してメンバーを探したい。なぜなら、マッチする人を探したいから。
- 応募後に通知で知りたい。

## ユースケースごとの受入条件

### UC-1 SNS共有
- [ ] 応募詳細画面にSNS共有ボタンが表示される
- [ ] 募集者が募集フォーム作成後にSNS共有ボタンから共有できる
- [ ] 共有された内容から詳細画面に遷移できる

### UC-2 募集一覧の閲覧
- [ ] ログインせずに募集一覧を閲覧できる
- [ ] 一覧画面に各募集が表示される
- [ ] 募集がない場合に専用の文言が表示される

### UC-3 会員登録・ログイン
- [ ] 会員登録できる
- [ ] ログインできる
- [ ] ログアウトできる

### UC-4 申し込む
- [ ] 募集詳細画面が表示される
- [ ] 募集詳細画面から申し込める
- [ ] ログイン前は申し込むボタンが表示されない
- [ ] ログイン前は「ログインしてください」と表示する

### UC-5 募集フォームに記入
- [ ] 新規作成画面が表示される
- [ ] ログイン前は新規作成画面に遷移できない
- [ ] 新規作成画面に募集内容を入力できる

### UC-6 通知（メール）
- [ ] 応募が来たことが通知される

## 非機能要件
- 他人の応募を編集・削除できない
